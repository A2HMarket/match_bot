# P36 — Agent框架评审与优化

2026-10-18，基于主干8076bca（0.22.0）审查，改动版本0.23.0。范围为packages/agent及计划、PoC、本文；没有SDK、依赖、表结构、Jev阈值变更。

## 判断与本轮改动

当前系统已有任务账本、来源核验、追问计划和出站门，主要缺口是执行循环没有充分使用这些边界。并非再加一份人格提示词就能解决。

| 问题 | 后果 | 本轮处理 |
| --- | --- | --- |
| record_task_progress登记deliver/ask_user后仍留在研究循环 | 搜索、记账、写答复混在同一长会话；writer只在失败收尾出现 | 接受当前进度后正常切换writer；只给reply_to_request，仍通过原出站门 |
| writer重放研究历史，并看见全部累计来源 | 重复计费，容易混用淘汰选项、添加无关事实 | 同一用户持久session内建立独立模型窗口；限选定来源与当前任务，快照保留来源编号与阶段 |
| 概括项可能把明确命中的候选挤出短名单 | 有明确激光机的证据，writer却只剩含糊打印机或空包 | 在限制短名单前优先当前支持的主体证据；无有效首选时从合格候选补位，不取已排除候选 |
| 部分追问直到出站才发现条件已经给过 | 无意义改稿消耗重试次数，最后只剩固定状态 | 登记前检查；writer也不继承旧计划里已知条件的追问，出站照常复核 |
| whole-source引用的quote=null被视为格式失败 | 真实来源已在服务器，仍因抄写引文失败丢失整个进度 | 服务器选取最多1000字原文摘录；仍做computed/Jev支持和矛盾检查，无法支持仍unknown。深处事实可用确切引文/已有passage |
| 10 am写为10:00被数字检查拒绝 | 模型改写成中文反而通过，属于格式误判 | 按时钟等价值处理已支持时间，再检查剩余数字；05:30不等于5:30pm，价格不作时钟证据 |
| 全部工具同时暴露；短追问又缺路由线索 | 工具混用或丢失原搭子需求 | 按当前任务收口研究工具；结合持久任务目标，保留catalogue原路径和官方信息搜索 |
| 研究占满时间，失败直接状态回复 | 有资料也来不及整理 | 总时限内预留30秒；受限超时/轮次耗尽有来源时尝试一次交付，Jev拒绝/输入耗尽不绕过 |

sourceQuote不把null等同于“已支持”：所有证据仍来自真实工具返回，显式伪引文仍拒绝；服务器摘录同样形成语义审核请求，缺失、矛盾、不完整保持未知。超过摘录范围的事实需要更精确来源，不能猜。六来源/24引用、硬条件、Phase 0/1/2、审批、Jev不可用降级、频控、出站表路径保持原规则。没有新出站路径或个人数据字段；新增的来源编号沿用原加密checkpoint的保留和删除路径。

## 静态与离线验证

- 完整pnpm check：134文件、1128测试通过。包含真实隔离Postgres/Redis的集成与worker契约。
- pnpm build通过。12条冻结多轮契约通过，92条录制入站评测precision=1、recall=1、silenceCorrect=1，categoryAccuracy=91/92。录制入站指标不能代表生成答案质量。
- 新增/扩展测试覆盖正常阶段切换、writer不回放研究工具历史、Phase 0演练/Phase 1审批恢复/Phase 2出站、来源白名单、旧版本快照失效、已知条件追问、模糊短追问工具路由、server-owned摘录仍需语义审核、时钟格式正反例。

仅内存审计P35三个合成checkpoint。原writer字符分别32168/27366/37379，新writer约8.9k/7.1k/9.4k，减少约72%–75%。同一配置的研究工具从16个减少为7/10/9个，writer仅1个。该审计adapter没有小红书全文读取能力，不能拿16当生产完整能力的工具数。字符减少并非模型token、延迟或用户满意度的实测改善。

## 尚未解决的框架问题

1. 研究工具仍累计返回来源，研究阶段仍会重复携带大包。本轮缩小交付阶段，尚未把研究上下文改成增量来源/按需阅读；它仍是主要token风险。
2. writer来源包需要更精确的字段级完整性。亲子案例有时间但缺总票价，GP诊断有泛化表述；Jev放行不等于实用性和每句话都正确。
3. 对少数数字事实的失败目前仍会落到固定状态。时钟误判已复现修复，但GP初测的数字1未取得足够定位证据，不能宣称同根已修。
4. 离线12契约保证状态和隔离，独立writer验证交付；两者都不能替代真实群里“搜索→发现缺口→主动补查→可行答复”的多轮验收。下一轮需保留同版本来源快照、execution fence和单次请求预算，以完整任务完成度计分，不能把测试器预算停止记作agent质量失败。

本轮完成结构修复并保留失败证据，不宣称已经解决人感或整体任务完成率。测试群维持停止状态；不自动消耗剩余26355token或发送新演员消息。
