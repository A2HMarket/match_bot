## DeepSeek 搜索

官方文档：[Search & Fetch](https://api-docs.deepseek.com/guides/search/)。独立原始 JSON Search API 为 `POST /v1/tools/search`，沿用 DeepSeek key；不是换生成模型，也未迁移到 Responses API。实测200、结构校验通过、能返回正文后才接入。

- `INFORMATION_SEARCH_PROVIDER=deepseek` 为默认值，可设 `tavily` 回滚。
- 既有 `WebSearch.research` 注入点、search_information 工具和来源 schema 复用。调用在 packages/agent，worker 只装配；shared 只添加 provider 环境契约，无新包/依赖/表。
- 请求正文，15秒超时，不盲目重试；无结果与HTTP/限流/超时/响应错误分开。HTTPS来源、域名过滤及脱敏保持。
- 商家联系方式核验仍委托原有 Tavily find；A2H公开物品/租房/帮带/搭子搜索、小红书Sandbase均保留。没有把所有数据源换成泛网页搜索。
- 工具提供实际来源URL和段落，便于后续定位官方入口；search trace记录provider，worker启动也记录provider。
- 原始Search按请求计费，不计入DeepSeek生成token。未使用Fetch：本次Search need_content已返回正文；不扩建无必要工具。
