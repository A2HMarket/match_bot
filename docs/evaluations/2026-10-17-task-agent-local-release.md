## 实测发现并修复的问题

1. **465pw混进£1600月预算备选**：旧逻辑跳过周租，误当价格未知。现在从用户Task携带计价单位并在审批恢复保留。明确周租连最短四周也超月上限时排除；保留原报价，不把推导下界伪装成月租报价。£335/周、含糊估价、押金、外币或总额口径不冒充已满足月租条件。真实文本备选回归及正反例通过。
2. **Jev响应体超时误记格式错误**：原群两次invalid_response未进入Task，原始trace不足以断言每次响应体实际内容；一次耗时约3007ms。冻结HTTP 200慢响应体复现：3.5秒正常响应被3秒上限中断，abort被误分类。默认单次上限改5秒，调用方更短deadline优先，超时仍不发；坏JSON仍拒绝。没有调Jev阈值或绕过门。
3. **worker初始化/关闭竞态**：全检实际复现“已closed却仍有计时器、需SIGKILL”。原测试保留并修复：连接ready后才启动消费，closing时不启动，关闭释放工厂拥有的Redis连接。没有延长测试超时或强制process.exit伪造自然退出。
4. **A3规格被当可变数字拒绝**：隔离真实模型复现两次相同start_task调用被拒；取消因没有Task而多问。用户原话与目标共同支持的A3/PS5/iPhone14/1b1b标识现在可进入对象核对标签；无出处标识、预算、日期、路程数值仍拒绝藏在无绑定标签中。真实模型修复前失败、修复后创建→取消同Task，以及原群复测均保留。
