# 隐私说明（给群管理员）

> 用途：管理员询问 Bot 在做什么时，直接发这份。对应 P13 §C「隐私说明文本准备好」。
> 本文只描述 Phase 0（只听不说）的实际行为，Phase 1 放行前需要另行取得管理员同意。

## 这个 Bot 在做什么

它读群里的公开文字消息，判断有没有人在找本地服务（搬家、退租清洁、家具安装/搬运）。
**Phase 0 阶段它不发任何消息**，只在后台统计，用来验证「群里到底有多少真实需求」。

## 它收什么

- 消息正文、发送者的 Telegram 数字 id、群 id、消息 id、时间
- 不收：手机号、邮箱、住址等联系方式；除非成员明确要求我们代为转达，才会记录

## 保留多久

- 消息正文**保留 30 天**，之后自动置空，只留一个不可还原的哈希值与结构化字段（品类、时间、区域）
- 哈希用于去重和审计，无法反推原文

## 它不做什么

- 不处理支付，不做担保，不代收款
- 不私信群成员
- 不把群成员信息卖给或转给第三方
- 租房、招聘、二手交易类消息只打标签，不做任何撮合

## 数据去了哪里

消息文本会发给两个模型服务用于判断与生成：Jev（TypeSafe AI，经 OpenRouter）与 DeepSeek。
两者都是 API 调用，不用于公开展示。

> ⚠️ **本节在 P13 §C+.1 解决前不要对外发**：Jev 侧的 Zero Data Retention 尚未落实与自证，
> DeepSeek 的数据处理条款也还没读过并记录结论。在能如实回答「你们的模型供应商会不会
> 拿这些消息训练」之前，不应向管理员承诺任何留存策略。

## 随时可以退出

管理员随时可以把 Bot 移出群。移出后我们会应要求删除该群的全部历史数据。
