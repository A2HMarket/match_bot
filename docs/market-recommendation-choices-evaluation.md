# P19 — 从结果列表到选择建议（0.13.0）

## 实际变化

- 首选1–3条，关键条件未确认的另列备选（有首选时至多2条，否则至多3条线索）。没有明确匹配时，明确说本次搜索未确认，不为了凑数量宣称全部符合。
- 推荐理由来自已核对的单品预算、地点、路线、日期及必要条件；单品价取该物品原文，不再同时重复整帖价格区间。详细介绍保留原句，房源额外展示同条原文租期/户型，帮带展示时间/计价/交接信息（至多两条）；这些信息不自动转为入住/航班已确认。原帖和A2H详情链接不变。
- 对在售物品，明确故障、划痕、两年未使用等原文风险后置并提示；无划痕不当成缺陷，也不把同帖另一物品的风险借过来。条件及风险相同才比较对应单品价；买家报价方向相反。
- 同一原帖同一源名称/物品重复导入去重；同一原帖不同物品、不同原帖同名物品均保留，不以名字相同就合并贴主。
- 明确入住时间、周末、初学者要求保留，即使模型漏填；“最好无线”维持可放宽偏好。普通查询类型不能悄悄代替用户明确要找的激光类型。
- 有候选后先读详情。有缺口且查询预算尚在时，出站前要求完成一次按源内供给名的定向补搜；只读GET，搜索8次/详情8次上限不变。仍无证据就标待确认，不借另一贴主的数据补全。

## 具体例子

“伦敦收激光打印机，预算60镑，最好无线”的最终真实预览：Brother £40先看，HP £50其次，三星£40因原文“两年没用”后置，并单独提示风险。三条的无线功能都没有证实，实际补搜后仍显示待确认；另列一条价格/地点尚不明确的Lexmark备选。不是承诺库存或机器功能已实测。

房源只列备选，因为11月初入住尚未确认；帮带保留正确上海→伦敦方向，显示年份/自动可用期冲突；搭子未把“新生”当“初学者友好”，周末与水平未证实仍标出。
