# P30 — 短句续接、回执版本竞争与无增量静默

基线main 66c91e6 / Agent0.18.2。用户指出“找药→急用且出不了门→头痛”最后一轮错误，明确偏好无帮助时不回复。生产只改packages/agent，复用Task、原出站门与do_nothing；无新工具/表/权限/依赖。

## 只读真实证据

头痛14:30:45 UTC入队，14:31:00.693取得用户执行锁，未与上一条同时处理。上一条出站14:31:00.545排队（Task revision12）；发送回执14:31:02.587改为revision13。头痛准备阶段14:31:03.378返回Error，随后single_task_reference_rejected并达到2轮上限；无信息搜索，却发查询失败/重复困难问题。需固定复现竞争，不能只改prompt。

## 验收（实施前冻结）

- [ ] 先复现旧任务版本12→发送回执13→用户补充写入冲突。仅同owner/scope、需求版本与用户目标/结果不变时刷新后重试一次；真实需求/结果变化不得重放旧patch，失败有明确trace。
- [ ] 短句背景应续接现有相关任务，不另建诊断目标或硬性药品匹配条件；保留急用/无法出门。多任务歧义和跨用户/群隔离仍有效。
- [ ] 已有同任务已送达回答的补充，在无新增有用信息时允许现有do_nothing安静结束，不被finalizer强迫发状态。首个独立请求、明确新问题不因此丢失；只读失败不伪装全网无结果。
- [ ] 准备失败且未绑定的短补充不发无上下文状态，不重复追问；失败留痕。出站phase/Jev/频控/拒绝规则不变。
- [ ] pnpm check/build/录制eval/12契约；一个有界三消息定向真实模型回放，所有结果保留。另用确定性真实PG或仓储回归证明版本竞争修复，不靠模型随机撞到。
- [ ] AGENT_VERSION递增，正常PR/CI/主干合并、本地launchd单例发布核验。不代替用户发送医疗信息到任何群。
