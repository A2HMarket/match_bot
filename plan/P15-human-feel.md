# P15 人感：会接话、像群友、有分寸

> 状态：**完成**（2026-09-25）。起因：用户读了 Meta Muse 的产品复盘，问「人感方面有没有可能提升」。
> 本轮只做前三项；第 4 项（有真正新进展才开口）、第 5 项（名字头像与自我介绍，需 BotFather 手动）待定。

## 诊断

最不像人的不是文案，而是**不接话**：`channel-telegram` 早就解析了 `replyToMessageId`，但流水线从未使用。用户回复 bot「这家周末开吗」「谢谢」，会和普通群消息一样先过 Jev 的需求门，几乎必被丢弃——发完一条就不理人。

## 做了什么

### 1. 会接话

- 适配层识别「对 bot 说的话」：回复 bot 的消息、`@bot_username`（不分大小写）、指向 bot 的 `text_mention`、以及私聊里的每一句。被回复的 bot 消息原文随消息带给 agent（`replyToBotText`，是 bot 自己说过的话，不含用户内容）；回复的是别人的消息则不带。
- 门控：这类消息**跳过需求门**直接进 agent（`kind: 'followup'`），敏感检查仍在最前。接话时取该用户最近一条未结需求作上下文，因为「谢谢」本身没有品类。
- 新工具 `react`：对「谢谢」「好的」加 👍 / 🙏，**不回文字**。表情反应不带内容，Phase 1 起不送审、不调 Jev、不占频控（AGENTS.md §3.3 第 3 条已写明此例外）；Phase 0 照旧只记录。发送端用 `setMessageReaction`。
- agent 被问「你是谁」时如实说：是 bot、信息来自一份审核过的小名单加公开搜索、群管理员可以关掉它。**不假装是人**。

### 2. 像群友说话

- 指令：第一人称单数（我，不说「我们」）；群回复 1–3 短句，不用标题、编号列表、网址，至多一个 emoji。
- web 搜索结果改为一行内联：`Tian Tian Market（instagram.com/tiantianmarket）、HIYOU（…）`，每家至多两种联系方式。
- 免责保留 PRD F7 的意思，改口语：库内「价格和档期直接找商家确认就好，我只是帮忙牵个线，不经手交易。」；搜索「这些是网上搜到的，我没核实过，建议先私信问问。」五语种同步。
- **顺带修掉一个已上线的 bug**：Instagram 此前写成 `@handle`，Telegram 会把它渲染成**同名 Telegram 用户**的链接，点进去可能是毫不相干的人（2026-09-24 那条华人超市回复已受影响）。改为 `instagram.com/handle`。

### 3. 有分寸

- 指令：群是公开的，只用用户在这段对话里说的内容；不在群里提起从别的消息里知道的事（搬家计划、住址、家人、健康、钱、其他请求）。session 按用户保存记忆，这条约束是必要的。
