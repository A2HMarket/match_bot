# P29 — 主动理解与本地购买渠道

基线 main 70abbe5 / Agent 0.17.3。用户提供“狗岛找止疼药”并要求主动使用现有工具找渠道，同时了解现实困难。单执行者，生产改动仅packages/agent；复用search_information、Task、reply_to_request和固定状态，不新增工具/表/权限/依赖。

## 已核验根因

同一请求先三次被market_search品类门拒绝；之后两次网页搜索成功（各5源）。草稿声称走过去就能买且夹带未请求用药建议，Jev mentions_unverified=0.56拒绝；固定状态随后将用户引向“先补哪项官方现价/时刻表”。原出站门有效，不调阈值、不重写拒绝绕过。

## 范围与验收（实现前）

- [x] 复现当前错误工具反馈与无关兜底；先失败测试再修改。
- [x] 解释用户目的→选择合法来源→必要时换搜索方向，而非重复被拒工具。一般本地购买/生活问题优先search_information；A2H只用于现有允许的交易/租房/帮带/搭子。
- [x] 缺少次要信息仍主动给已核实渠道并问一个影响行动的困难；不把未知字段清单交用户选择。医药只查正规获取渠道、店家官方页/NHS，无库存保证、诊断、用药品种/剂量推荐或公开病历追问。
- [x] 固定状态仍代码封闭、无实体/链接/数字，不能变成拒绝推荐的第二出口；已知困难不反复问。

- [x] AGENT_VERSION递增，pnpm check/build、录制eval和既有12契约通过。正常PR/CI/合并后沿用本地launchd单例发布与核验。
