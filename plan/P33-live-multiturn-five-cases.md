## 范围与验收

冻结 Main Agent 0.20.0 和生产门规则，场景依次为激光打印机、养猫租房、羽毛球搭子、GP 注册、亲子看展。演员仅知道自己的需求和实际收到的答复，不获得评分标准、不假装完成购买或报名。失败原样保留，不在批次中调整提示词筛选答案。

链路为演员生成 → Jev/阶段/频控 → 出站表/真实 Telegram 发送 → Main 入站/用户 session/研究工具 → Main 出站发送 → 演员跟进。跨账号群消息 ID 不通用，原生回执不可用时，仅以同一来源、同一群的已发送公开答复作为转录观察；不冒充原生 Bot 更新，不伪造 replyTo。未收到当前请求答复就结束，不拿旧回复续聊。

复用 apps/bot 测试控制器与 packages/db 出站仓储，新增只读 findReplyForSource；无新表、迁移、依赖、生产出站路径或个人数据字段。模拟对话保存在忽略的本地日志目录，凭证不进入报告或 Git。
